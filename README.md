# 电脑工作台 · Windows 下载

Windows x64 便携版，包含 .NET 运行时。完整解压后双击 `Start.cmd`。

- [GitHub 最新版及更新说明](https://github.com/Earthling18/desktop-dashboard-releases/releases/latest)
- [阿里云版本列表](https://cc-launcher-dist.oss-cn-shanghai.aliyuncs.com/desktop-dashboard/releases/releases.json)
- 应用内入口：应用设置 → 常规 → 版本更新。阿里云优先，GitHub 备用。
- 两个下载渠道只保留最近 **3 个正式发行版本**，包提供 SHA256 校验信息。

新版本下载后，退出工作台，用完整新版包更新原程序目录。工作台、CC 与 Reminder 的个人配置及数据位于程序目录之外，不包含在通用发行包中。

本仓库只发布通用软件包、版本信息和分发工具。分发任务通过 CC 仓库独立的工作流执行，OSS 清理仅限 `desktop-dashboard/releases/` 目录；上传与公开下载验证完成后才清理旧包。
